# Semana 4
lina 1 manual 
Requerimientos funcionales

1. Buscar estaciones
El usuario escribe el nombre de una estación y el sistema devuelve su información clave.

2. Buscar por línea
Ingresas el número de línea y te muestra todas sus estaciones.

3. Mostrar conexiones
Si una estación conecta con otra línea, indica con cuál y en qué estación.
Ejemplo del enunciado: buscar Grau y ver con qué línea conecta.

4. Mostrar servicios
Indicar si la estación cuenta con ascensor.

5. Filtrar estaciones
Poder filtrar y mostrar características de las estaciones.

6. Aplicación de consola
Todo funcionando por terminal con menú interactivo.
