# Actividad Propuesta 02 — Clientes de un Banco

## Requerimientos funcionales

- Registrar un cliente con codigo, direccion, fecha de registro, numero de cuenta y monto minimo de apertura
- Registrar un cliente natural con nombre completo y DNI, heredando los datos comunes
- Registrar un cliente juridico con razon social, RUC y representante legal, heredando los datos comunes
- Mostrar los datos de cada tipo de cliente sobrescribiendo el metodo MostrarDatos de la clase base
- Recorrer una lista de clientes e imprimir sus datos con un solo bucle, aplicando polimorfismo
